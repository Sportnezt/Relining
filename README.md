# relining.info – v0.2

Första webbstartsidan enligt planen för relining.info.

## Filer
- `index.html` – startsidan
- `styles.css` – all layout/design
- `script.js` – mobilmeny
- `assets/logo.svg` – enkel temporär logotyp
- `assets/favicon.svg` – favicon

## Publicering
Fungerar som statisk webbplats på GitHub Pages, Netlify eller liknande.

## Nästa steg
1. Fastställ logotyp.
2. Bygg de riktiga undersidorna.
3. Lägg in källor och tekniskt innehåll.
4. Bygg målgruppsvägarna.
5. Lägg till kostnadskalkylator.
6. Bygg branschregister/entreprenörsregister.
7. Lägg till diskreta annons- och företagsprofilytor när trafik finns.

E-postadressen i startsidan är en placeholder och ska ändras innan publicering om annan adress ska användas.
