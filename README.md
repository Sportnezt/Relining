# relining.info – version 3

Riktig grundstruktur för webbplatsen.

Innehåller:
- startsida
- separata huvudområden
- sex målgruppssidor
- expanderbara sektioner
- FAQ med sökfunktion
- meddelandelänk om ingen FAQ-träff hittas
- tangentbord 1–6 på startsidan
- gemensam navigation
- mobilanpassning

Obs: FAQ använder `info@relining.info` som exempeladress. Byt till den riktiga mottagaradressen innan publicering.
