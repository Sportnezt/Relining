# relining.info

Detta är den kompletta webbversionen av relining.info.

## Uppladdning
Ladda upp **innehållet i denna mapp** till GitHub-repositoryts root. Behåll mappstrukturen.

Viktigaste filer:
- `index.html` – startsida
- `styles.css` – gemensam CSS
- `script.js` – JavaScript
- `logo.svg` – logotyp
- undermappar med respektive `index.html` – undersidor

## Struktur
Sidorna använder relativa länkar så att webbplatsen fungerar på GitHub Pages och vanlig statisk webbserver.
